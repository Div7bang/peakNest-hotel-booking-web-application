PeakNest is a full-stack hotel booking platform for Himalayan destinations such as Shimla, Manali, Dharamshala, Kasol and Spiti Valley. Visitors can browse destinations, hotels, rooms and deals, and open a detail page for each hotel with its gallery, amenities and pricing. Guests can sign up and log in, while admins get a separate login that leads to a protected dashboard.

The backend is built with Node.js, Express and MongoDB (via Mongoose) in an MVC structure, with separate folders for routes, controllers, middleware and models. Authentication uses bcrypt password hashing, JWT tokens and MongoDB-backed sessions, and a role-check middleware keeps admin routes limited to admins. The admin dashboard shows user statistics and lets admins manage users and hotels, with full create, read, update and delete operations for hotels. The front end uses EJS templates with custom CSS, and a default admin account is created automatically from environment variables when the server first starts.
